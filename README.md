# المشكاة ستور

واجهة متجر إلكترونيات عراقية عربية متجاوبة، تعرض الأقسام والمنتجات والعروض وخدمات التوصيل والضمان في تجربة RTL مصممة للهواتف وسطح المكتب.

## التقنيات

- React 19 وTanStack Start
- Tailwind CSS 4 مع تصميم CSS مخصص
- Lucide React للأيقونات
- Netlify للنشر والتشغيل

## التشغيل محلياً

يتطلب المشروع Node.js 22 وpnpm.

```bash
pnpm install
pnpm dev
```

يفتح خادم التطوير افتراضياً على `http://localhost:3000`.
